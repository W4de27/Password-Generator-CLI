# 🔐 Password Generator CLI 2.0 🔐

A **secure**, **fast**, and **interactive** command-line password generator built with Python.  
Generate passwords of varying strengths—from easy to impossible—right in your terminal, with a beautiful animated interface and error handling.

---

## Features

- Multiple password strength levels:
  - **Easy** (8 characters)
  - **Normal** (10 characters)
  - **Hard** (12 characters)
  - **Impossible** (16 characters with symbols)
- Animated loading effects for better user experience.
- Interactive menu with error handling for invalid inputs.
- Visually appealing terminal interface with ASCII art and icons.
- Easy to extend and customize for your needs.

---

## Installation & Usage

Follow these steps to run the project on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/W4de27/password-generator-cli.git
```
### 2. Navigate to the project folder
```bash
cd Password-Generator-CLI
```
### 3. Run the program
```bash
python password-generator.py
```
